Dataset: wine_quality.csv — 900 wine samples with 11 chemical features and a quality score (3-8).

3. Class Imbalance Discussion¶

Discussion: Quality scores 3, 4, 7, and 8 are significantly underrepresented compared to 5 and 6. This means a model can achieve deceptively high accuracy simply by always predicting 5 or 6, while completely failing on rarer classes. To make the problem more tractable and reduce the impact of imbalance, we bin quality into 3 broader classes below.

4. Feature Engineering — Bin Quality into 3 Classes¶

In [5]:
def bin_quality(q):
    if q <= 4:
        return "Low"
    elif q <= 6:
        return "Medium"
    else:
        return "High"

df["quality_class"] = df["quality"].apply(bin_quality)
df["quality_class"].value_counts()

Justification: Binning into Low/Medium/High reduces the number of classes from 6 to 3, keeps the classes better populated, and better matches a practical business question ("is this wine good, average, or bad?") rather than predicting an exact score.

6. Train 3 Classifiers¶

In [7]:
models = {
    "Random Forest": RandomForestClassifier(n_estimators=200, random_state=42),
    "SGD Classifier": SGDClassifier(random_state=42, max_iter=2000),
    "SVC": SVC(kernel="rbf", random_state=42)
}

results = {}
for name, model in models.items():
    model.fit(X_train_scaled, y_train)
    pred = model.predict(X_test_scaled)
    results[name] = pred
    print(f"--- {name} ---")
    print(classification_report(y_test, pred))

10. Conclusion¶

Random Forest typically performs best here since it handles non-linear feature interactions well and is robust to the remaining class imbalance. For deployment, Random Forest is the most suitable choice: it gives interpretable feature importances (useful for winemakers) alongside strong predictive performance, whereas SVC and SGD are more sensitive to the imbalance between the Low/Medium/High classes.
